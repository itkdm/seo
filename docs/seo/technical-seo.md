# 新站技术 SEO 清单：先把基础做好

技术 SEO 的基础工作，是让搜索引擎能访问重要页面，让访问者能顺畅阅读和完成任务。先处理影响全站和关键页面的问题，不必追逐每一个评分工具的提示。

## 抓取与索引

- 页面返回正常状态码，重要内容不依赖搜索引擎无法访问的交互。
- 检查 robots 规则没有误拦重要内容。
- 为重要页面提供稳定链接，避免产生大量重复 URL。
- 根据站点规模生成并提交 sitemap。

## 页面信息

- 每个页面使用清晰、独特的标题和描述。
- 标题层级表达内容结构，不把标题仅用作视觉样式。
- 设置规范 URL，必要时声明 canonical。
- 图片有描述性的替代文本，文件大小适合页面用途。

## 体验与结构

- 在手机和桌面检查内容、导航与主要操作。
- 提供清楚的分类、面包屑和相关页面内部链接。
- 检查加载速度、字体和图片是否影响阅读。
- 使用结构化数据前，先保证页面本身内容准确且可见。

上线后定期检查搜索控制台的索引与体验报告，并优先修复真实影响用户或抓取的错误。
