# SEO 增长

搜索引擎优化不是追逐技巧，而是理解用户搜索问题的方式，提供有帮助、可信且方便访问的页面。对新站来说，清晰的主题、合理的网站结构和持续解决实际问题的内容更重要。

<div class="guide-note"><strong>本阶段的结果：</strong> 一张主题与关键词地图、一套内容发布节奏，以及可以持续观察的收录和自然流量数据。</div>

- [新站技术 SEO 清单](/seo/technical-seo)：检查抓取、索引、页面体验和基础元数据。

## 从搜索意图开始

先弄清用户为什么搜索，以及他们希望在结果页看到什么。教程、工具、对比、产品页服务不同意图，不应只为了塞入关键词而拼在一起。

## 让网站结构帮助读者

围绕主题组织页面，通过清楚的导航和内部链接连接相关内容。每个页面解决一个明确的问题，标题、描述和正文保持一致。发布后持续检查页面是否被发现、收录，是否带来目标用户。
